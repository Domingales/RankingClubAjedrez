RANKING CLUB AJEDREZ v2.3.0
============================

Esta versión parte de la v2.2.0 y mantiene la misma conexión Firebase ya configurada.

PARA ACTUALIZAR GITHUB PAGES
1. Sustituye en el repositorio los archivos/carpetas de esta versión por los actuales.
2. Haz Commit changes.
3. Espera a que GitHub Pages publique el cambio.
4. Recarga la app con Ctrl+F5 en ordenador o cerrando/reabriendo la página en móvil.

NO HACE FALTA CAMBIAR FIREBASE
- Authentication permanece igual.
- Firestore permanece igual.
- No hay que crear otra API key.
- No hay que volver a publicar reglas para usar el editor de perfil con las reglas actuales.

NOVEDAD PERFIL
- El nombre conectado se ve en la cabecera también en móvil y al tocarlo abre "Mi perfil".
- El menú lateral muestra nombre y correo.
- "Editar datos" permite modificar el nombre visible.
- El correo queda bloqueado para evitar desincronizarlo con Firebase Authentication.
- "Cambiar contraseña" envía un enlace seguro al correo mediante Firebase Authentication.
- Rating, RD, volatilidad y estadísticas no son editables.
